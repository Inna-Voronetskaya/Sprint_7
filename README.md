# Sprint_7 — Тесты API для Яндекс Самоката

## Описание

Автотесты для API учебного сервиса **Яндекс Самокат**.

## Структура проекта

- `api/` — методы для работы с API
- `helpers/` — вспомогательные функции и генерация данных
- `tests/` — тесты
- `allure-report/` — готовый HTML-отчёт
- `config.py` — настройки (BASE_URL, статусы, тексты ошибок)
- `conftest.py` — фикстуры

## Установка

```bash
pip install -r requirements.txt
```

## Запуск тестов

```bash
pytest tests/ -v
```

## Отчёт Allure

```bash
pytest tests/ --alluredir=allure-results --clean-alluredir
allure generate allure-results -o allure-report --clean
allure open allure-report
```
